# n8watkins Homebrew tap

```sh
brew install n8watkins/tap/pass-env    # run programs with secrets from pass
brew install n8watkins/tap/devguard    # run many AI coding agents without running out of memory, ports or disk
```

The formulas in `Formula/` are written by each tool's release workflow ([pass-env](https://github.com/n8watkins/pass-env), [devguard](https://github.com/n8watkins/devguard)); do not edit them by hand.
Each one installs that release's standalone build, checked against its SHA-256.
